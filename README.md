# Tokumei

Личное рабочее пространство для структурирования данных, генерации вымышленных персонажей и временной почты.

## Запуск

В каталоге репозитория выполните команду и откройте [http://localhost:8000](http://localhost:8000).

```bash
python -m http.server 8000
```

Для публикации подойдёт любой статический хостинг с HTTPS. Приложение использует HTML, CSS и JavaScript без шага сборки.

## Возможности

- **Данные.** На карте связей можно вручную соединить людей, телефоны, аккаунты, ссылки и заметки. В разделе «Записи» доступны категории, теги, поиск и свои поля.
- **Персонажи.** Выберите возраст, пол, язык имени, характер и стиль общения. Имя, фамилию и род занятий можно задать вручную. Профиль можно сохранить, скопировать и связать с временным адресом.
- **Почта.** Создавайте временные адреса на один час, копируйте их и читайте входящие. Браузер обращается напрямую к [Nextmail](https://nextmail.sh/docs/api/temp-mail/create).

Карта связей, записи, профили и доступ к временным ящикам хранятся в этом браузере. Резервная копия JSON включает карту связей, записи и вымышленные профили. Почтовые ящики управляются в разделе «Почта».

## Импорт записей

Выберите файл резервной копии Tokumei или JSON-файл с массивом записей. Для записи достаточно поля `title`.

```json
[
  {
    "title": "Идеи для проекта",
    "category": "Проекты",
    "tags": ["работа"],
    "notes": "Подготовить первый прототип",
    "url": "https://example.com",
    "fields": [{"name": "Этап", "value": "Планирование"}]
  }
]
```
