# Tokumei

Личное рабочее пространство для структурирования данных, генерации вымышленных персонажей и временной почты.

## Запуск

В каталоге репозитория выполните команду и откройте [http://localhost:8000](http://localhost:8000).

```bash
python -m http.server 8000
```

Интерфейс использует HTML, CSS и JavaScript без шага сборки. Вход обслуживает функция `tokumei-auth` на Supabase. Для своей установки примените `supabase/tokumei-auth.sql`, разверните функцию из `supabase/functions/tokumei-auth` с `verify_jwt = false` и укажите её адрес в `js/auth.js` и в CSP страницы. Функция проверяет собственные токены сессий. Разрешённые адреса интерфейса перечислены в функции.

## Возможности

- **Учётная запись.** Регистрация по логину и паролю. Логин можно сгенерировать при регистрации. Для каждого аккаунта используется своё рабочее пространство в браузере.
- **Данные.** Можно вести до трёх карт связей и соединять на них людей, телефоны, аккаунты, ссылки и заметки. Площадка определяется по ссылке или выбирается вручную. Значки площадок взяты из [Simple Icons](https://simpleicons.org/). В разделе «Записи» доступны категории, теги, поиск и свои поля.
- **Персонажи.** Выберите возраст, пол, регион, город, характер и стиль общения. Генератор подбирает имя с учётом региона и добавляет предысторию и увлечение. Имя, отчество, фамилию и род занятий можно задать вручную. Профиль можно сохранить, скопировать и связать с временным адресом.
- **Почта.** Создавайте временные адреса на один час, копируйте их и читайте входящие. Браузер обращается напрямую к [Nextmail](https://nextmail.sh/docs/api/temp-mail/create).

Карты связей, записи, профили и доступ к временным ящикам хранятся в этом браузере. После входа прежние локальные данные можно перенести в текущую учётную запись. Резервная копия JSON включает все карты, записи и вымышленные профили. Копии прежнего формата добавляют узлы и связи в первую карту. Почтовые ящики управляются в разделе «Почта».

Для учётных записей хранятся логин, хеш Argon2id с солью и хеши токенов сессий. Счётчики попыток входа привязаны к учётной записи и общему лимиту запросов. Tokumei работает без журналов IP и аналитики. Сетевые журналы GitHub Pages и Supabase описаны в разделе «Приватность» интерфейса.

## Импорт записей

Выберите файл резервной копии Tokumei или JSON-файл с массивом записей. Для записи достаточно поля `title`.

```json
[
  {
    "title": "Идеи для проекта",
    "category": "Проекты",
    "tags": ["работа"],
    "notes": "Подготовить первый прототип",
    "url": "https://example.com",
    "fields": [{"name": "Этап", "value": "Планирование"}]
  }
]
```
