Приватность

Записи, карты связей и персонажи остаются в браузере. Сервер входа хранит логин, хеш пароля с солью и данные сессии. Для защиты входа используются кратковременные счётчики попыток без привязки к IP. В Tokumei нет аналитики.

GitHub Pages сохраняет IP-адреса посетителей для безопасности хостинга. Документация GitHub

Запросы входа обрабатывает Supabase. Платформа ведёт технические журналы запросов. Документация Supabase

Временные ящики и входящие письма обрабатывает Nextmail. Браузер обращается к нему напрямую и сохраняет доступ к ящикам в своём хранилище.
